# 기사 작업실 시작하기

1. Python 3.10 이상을 설치하고 ZIP을 풉니다.
2. 워크스페이스 최상단(`appCoreTest/`)에 `.env`를 만들어 필요한 값을 채웁니다. 개발은 `AI_BACKEND=local` + `OPENAI_API_KEY`(제목·부제·흐름·이미지) + `UNSPLASH_ACCESS_KEY`(사진 검색)입니다. 팀 백엔드·DB 연결은 `AI_BACKEND=remote` + `AI_BACKEND_URL`(Render) + `SUPABASE_URL` / `SUPABASE_ANON_KEY`(로그인·공유)이고, 연결 상태는 `python dev/checks/backend_check.py` 로 확인합니다. 실제 키가 들어 있는 `.env`는 GitHub에 올리지 않습니다.
   - **공용 테스트 계정 자동 로그인(개발 실행 전용):** Supabase 대시보드 → Authentication → Users → Add user 로 팀 공용 계정을 만들고, 각자 `.env` 에 `TEST_ACCOUNT_EMAIL` / `TEST_ACCOUNT_PASSWORD` 를 넣습니다(팀원에게는 메신저 등으로 따로 전달, 저장소에 올리지 않음). 앱을 열면 그 계정으로 자동 로그인되고 토큰은 만료 전에 알아서 갱신됩니다. 헤더의 '테스트 계정 자동 로그인' 버튼으로 끄고 켤 수 있고(이 PC 에 기억), 기본값은 `.env` 의 `AUTO_LOGIN`(없으면 켜짐)입니다. 배포본(exe)에서는 동작하지 않습니다.
3. 이 폴더에서 `start_windows.bat`을 실행합니다. 빈 포트(8877~)를 골라 서버를 띄우고 시작 화면까지 확인한 뒤 기본 브라우저로 엽니다. 명령으로는 `python app\launcher.py` 입니다.
4. 주소는 실행할 때 콘솔에 표시됩니다(보통 http://127.0.0.1:8877). `.env`를 고친 후에는 다시 실행합니다.
   - 8765 고정 주소로 쓰던 방식은 `python app\server.py` 입니다(다른 프로그램이 그 포트를 쓰면 안내 후 종료합니다).
   - 다른 프로그램이 쓰는 포트는 건너뛰므로 그 프로그램을 방해하지 않습니다.

패키지를 따로 설치할 필요는 없습니다. API 키 없이도 기사 작성, 사진 첨부와 플랫폼 미리보기는 동작합니다. 제목·부제목 추천, 글 흐름, 이미지·사진 설명 생성에는 OpenAI API 연결 및 사용료가 필요합니다. 원고는 현재 브라우저에 자동 저장되므로 같은 주소와 브라우저로 다시 여세요.

## 데스크톱 창으로 실행 (선택)

브라우저 대신 네이티브 창으로 열 수 있습니다. 셸은 `pywebview`(Windows = WebView2, macOS = WKWebView)만 담당하고 화면· 코어·HTTP 계약은 그대로입니다.

```
pip install pywebview
start_window.bat                     # 더블클릭용(창 모드, 권장)
start_windows.bat --window           # 같은 동작(인자로 지정)
python app/launcher.py --window      # 명령으로 직접
```

- 개발 중에는 오류를 보려고 콘솔 창이 함께 열립니다. 콘솔 없이 사용자용처럼 띄우려면 배포본 `dist\AINewsroom\AINewsroom.exe`(기본이 창 모드)를 쓰세요.

- 창을 닫으면 서버도 함께 종료됩니다. 기존 브라우저 모드(`start_windows.bat`)는 그대로 동작합니다.
- 창의 임시 저장(IndexedDB)은 `article_editor/.article-workspace/webview`에 남습니다(앱 폴더와 함께 옮기면 포터블).
- 자동 검증: `python app/desktop/smoke.py --mode write` → `python app/desktop/smoke.py --mode read`
  (창 부팅, 코어 연결, IndexedDB 영속, 드롭 이벤트 전달을 확인합니다. 자세한 내용은 `app/desktop/README.md`)
- 코어 서버는 창과 같은 프로세스의 스레드에서 돌고, 창을 닫으면 함께 종료됩니다. `.env`와 `.article-workspace`는 앱 폴더 기준입니다.

## 배포본(exe)으로 실행

Python 설치 없이 창으로 실행되는 실행 파일을 만들 수 있습니다.

```
packaging\build_windows.bat                       # 빌드(몇 분)
dist\AINewsroom\AINewsroom.exe                    # 실행(창 모드)
dist\AINewsroom\AINewsroom-debug.exe --check      # 진단(창 없이)
dist\AINewsroom\AINewsroom-debug.exe --smoke write
```

- 저장 위치(2026-10-06): 기사·취재자료 원본은 **`내 문서\AI Newsroom\`**, 모델·캐시·로그·창 데이터는 `%LOCALAPPDATA%\AI Newsroom\`. `.env`는 `%LOCALAPPDATA%\AI Newsroom\` 또는 exe 폴더에서 읽습니다. 예전 `.article-workspace\`는 첫 실행 때 자동으로 옮겨집니다.
- 로컬 제목·부제 모델(ONNX, 매니페스트로 설치)은 배포본에 넣지 않습니다. 제목·부제 추천은 기본적으로 원격 AI를 씁니다.
- 자세한 내용과 문제 해결은 `packaging/README.md`를 보세요.
- 로컬 모델 설치는 **첫 사용 때 1회**입니다(설계 B). `%LOCALAPPDATA%\AI Newsroom\models\`에
  내려받습니다(제목·부제 모델 캐시 `models\hf\` 도 같은 폴더 안). 상태·설치는 `python app\launcher.py --models` (사내망은 `--models install --from "\\서버\경로"`).


## 기사 작성

- 본문을 80자 이상 작성하고 잠시 멈추면 빈 제목과 부제목만 자동으로 채웁니다. 이미 작성한 문구는 새로고침해도 유지되며, 새 문구를 원할 때는 항목별 ‘다시 만들기’를 누릅니다.
- 글자를 선택해 굵게·기울임·밑줄·취소선을 적용할 수 있습니다. 본문 문구를 선택하고 ‘● 소제목’을 누르면 두 플랫폼의 미리보기에 반영됩니다. 취소선 표시된 글은 원고에는 남고 미리보기와 AI 분석에서 제외됩니다.
- 사진은 보관함에서 원하는 문단으로 끌어 넣을 수 있습니다. 본문 사진을 잡아 움직이면 반투명 삽입 위치가 나타나고 화면 위아래 가장자리에 가까워지면 자동 스크롤됩니다.
- AI 이미지 생성 전에 설명을 확인하고 수정합니다. 생성된 사진 설명에는 ‘AI로 생성한 이미지’가 표시됩니다.
- ‘글의 흐름 보기’ 창은 이동·크기 조절이 가능하고 ‘새로고침’을 누르면 현재 문단 흐름을 정리합니다.

## 사진 파일 크기 변경

- JPG·PNG·WebP 원본의 픽셀과 파일은 그대로 보관합니다. 첨부한 사진과 AI 생성 이미지에는 플랫폼별 **실제 픽셀 크기가 다른 파일**을 따로 만듭니다.
- 동아일보용 최대 가로 **684px**, 네이버용 최대 가로 **666px**. 세로는 원본 비율에 따라 계산합니다. 예: 1200×800px → 각각 684×456px, 666×444px.
- 작은 원본은 확대하지 않습니다. 자르거나 여백을 넣지 않으며, 큰 사진의 축소 파일은 브라우저에서 새로 인코딩됩니다. 화면 미리보기에는 해당 플랫폼의 축소 파일을 사용합니다.
- 사진 보관함에서 ‘동아일보용 파일 받기’ 또는 ‘네이버용 파일 받기’를 누르면 실제 업로드 가능한 파일을 내려받습니다. 원본에 사진 설명·촬영일이 들어가 있더라도 새 파일에는 사진 자체만 담깁니다. 기사 사진 설명과 출처는 원고 편집기에서 별도로 관리합니다.
- **이 파일이 동아일보·네이버의 업로드 규격에 맞는지는 별도 확인이 필요합니다.** 현재 폭은 미리보기의 기사 본문 폭 기준이며 두 사이트에 직접 발행하거나 업로드하지는 않습니다.

## 연결 범위

Supabase 관련 SQL과 예제는 `integration/`에 있으며, 현재 로컬 사진 보관함과 자동 연결된 상태는 아닙니다. 서버에 원고를 저장하지 않고 브라우저 IndexedDB에 저장합니다. 브라우저 데이터를 지우거나 다른 브라우저·주소를 사용하면 원고가 보이지 않을 수 있습니다. AI를 사용할 때에는 원고가 OpenAI로 전송되고, 사진 설명 기능은 선택한 사진도 전송합니다.

기본 문법과 이미지 축소 치수 계산은 검사했습니다. 실제 브라우저에서 사진 다운로드·드래그와 유료 API 결과는 아직 별도 확인이 필요합니다.
