# research/ — 모델 연구 공간

앱(`article_editor/`)과 분리된 실험 공간이다. 규칙:

- 연구 하나 = 폴더 하나(`research/<주제>/`). 그 안에 `README.md`(목표·기준선·실행법), `scripts/`, `data/` 를 둔다.
- **실험 산출물은 커밋하지 않는다** — 각 폴더의 `.gitignore` 가 `runs/`(어댑터·체크포인트·평가 결과)와
  `data/sealed/`(봉인 평가셋)를 막는다. 앱 코드는 읽기만 하고(import), 여기서 앱 파일을 고치지 않는다.
- 결과가 앱에 들어갈 만하면 승격 절차(평가 통과 → 모델 매니페스트 → 앱 코드)를 따로 밟는다.
