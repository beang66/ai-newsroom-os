# v0.2 감사 수정 기록 — 2026-09-27

## 수정 순서와 결과

1. **표시 범위 정정**: 기사 검토 보조/검색 후보로 명명. 모델 confidence를 사실 신뢰도로 표시하지 않음. 키 설정과 연결 성공을 구분. 지도 표시 개수와 의미 없는 좌표를 고지. 미구현 편향·문체·맥락 심사를 명시.
2. **데이터 계약**: API 2.0, 기사 ID/버전/해시, 문장 코드포인트 범위, 원본 SHA-256/바이트, 페이지·문단·표 셀·행 위치, 후보 발췌 범위. 원본과 일치하지 않는 후보를 저장 단계에서 거부. 자료 변경 중 검토 저장 거부. 자료 삭제 시 연결 검토도 삭제.
3. **책임 분리**: 검색 Retriever, 판정 Judge, 저장 ReviewRepository 인터페이스. 검토 서비스는 HTTP/SQLite/TypeSafe 직접 import 제거. 서버에서 어댑터 조립. 기본 UI는 독립 데모이고 기존 React UI에 그대로 끼우는 컴포넌트라고 주장하지 않음.
4. **반례 검증**: 아래 자동 테스트 통과. 실제 브라우저 렌더링과 실제 Jev 호출은 수행하지 못했음.

## 실패를 통해 추가로 수정한 내용

첫 회귀 테스트 실행에서 '이야기'의 '야기'를 인과 표현으로 잡는 오류가 드러났습니다. 단어 내부 일치를 제한하고 해당 입력을 회귀 테스트에 유지했습니다.

## 검증하지 못한 것과 한계

- 브라우저 실행 파일 다운로드가 실패하여 실제 데스크톱/모바일 화면 검증은 미완료입니다.
- 실제 TypeSafe 계정 키가 없어 실호출, 지연 시간, 비용, 한국어 판단 정확도는 미검증입니다. wire contract는 공개 공식 SDK의 형태를 참고하고 모의 transport로 검사했습니다.
- 이 테스트 개수는 기사 검증 정확도를 뜻하지 않습니다. 기자가 라벨링한 별도 평가 세트가 필요합니다.
- 검색은 일부 조사 제거/부분 문자열 기반입니다. 형태소 분석·의미 검색이 아니며 다의어·이름·동의어 오류가 남습니다.
- 유형 분류와 수치·부정 비교는 경고 생성 규칙입니다. 문장 분리도 약어·인용부호·복합 문장을 완벽히 해석하지 않습니다.
- 프롬프트 인젝션 탐지는 일부 패턴만 차단합니다. 완전한 방어·모델 무오류를 보장하지 않습니다.
- 대규모 파일 처리와 다중 사용자 배포용 시스템이 아닙니다. 키워드 검색은 로컬 전체 블록을 순회합니다.

## 기획 정정

현재 제품 정의는 **'기사가 어떤 자료와 연결되는지 검토하는 보조 도구'**입니다. Jev의 구조화된 응답만으로 논리·편향 판단 성능을 주장하지 않습니다. Graph DB 도입은 필수가 아니며 실제 관계 탐색 요구와 성능 측정 후 결정합니다. 공식/익명 같은 출처 유형을 단일 신뢰도 점수로 바꾸지 않습니다. 추후 평가에서는 원출처·방법론·시점·독립성·주장과의 직접성을 나누어 확인해야 합니다.
