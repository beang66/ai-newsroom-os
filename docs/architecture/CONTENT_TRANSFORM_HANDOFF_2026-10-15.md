# 콘텐츠 변환 작업 공유 — 2026-10-15

대상 브랜치: `feature/platform-generator`. 오늘의 변경을 합쳐 공유하는 기록이다. 세부 문서의 테스트 수와 작업 상태는 각 단계 시점의 기록이며 최종 검증 범위는 아래를 따른다.

## 변경 내용

1. 카드뉴스 본문: headline → answer → detail의 역할을 생성·교정·검수 지침에서 맞췄다. 질문형·명사형·서술형을 허용하며 같은 카드에서 답·조건을 완결한다. 주요 정보 배분과 사실·근거 검사는 유지한다. 표지·마지막 카드 규칙은 바꾸지 않는다.
2. JPG 준비: 공용 템플릿의 목록 끝 장식에 의한 높이 초과를 수정하고 필드별 측정 오류를 표시한다. 문안 생성과 JPG 준비를 구분하며 정상 이미지를 재사용한다. 편집한 카드만 다시 확인하고 다른 기사·고정본 이미지는 재사용하지 않는다. 일부 카드만 SNS에 넣지 않는 정책은 유지한다.
3. SNS 연결 UI: Instagram과 Threads 모두 로그인 연결/작성창 채우기의 두 버튼으로 정리하고 상태를 직렬 자동 조회한다. 기존 작성창·입력 보존, 중복 요청·늦은 응답·창 닫힘 처리를 보강했다. Instagram 전용 창만 Chrome으로 고정하며 Threads 및 JPG 렌더러의 브라우저 선택은 유지한다. 실제 게시 동작은 추가하지 않는다.
4. 기사 연결: HTML 비교에 기존 본문 변환 경로를 사용한다. 기사 복원 시 다른 기사의 플랫폼 필드를 상속하지 않는다. 원문·조건·생성 작업을 연결하고 오래된 응답의 혼입을 차단한다. 이전 결과는 보존하되 현재 원문 결과와 구분한다.
5. 제한적 형식 복구: Instagram 닫는 따옴표 문장 판정·태그 형식을 보완하고 AI가 새로 선택한 부적합 비교형만 문안·근거 보존 상태로 설명형에 대체한 뒤 기존 검수를 유지한다.
6. Threads 기본 반말: 생성·검수·화면의 감지 기준을 연결하고 필요한 문단만 한 번 교정한다. 교정 요청은 말투에 한정하며 문단 번호로 응답을 연결한다. 수치·인용 변경 및 말투 잔존 등의 실패를 구분한다. 저장 원고를 자동 수정하지 않는다.

## 최종 검증

- `npm test`: API 경계 검사 및 58개 테스트 통과.
- `node --test platform-generator/tests/*.test.cjs`: 93개 테스트 통과. 개발/프로덕션 화면, 합성 SNS DOM, 기존 카드 구조·근거, 실제 JPG 렌더, 검색 모의 환경 회귀를 포함한다. 유료 AI나 실제 SNS 게시를 실행한 테스트가 아니다.
- `npm run build`: 통과. 생성된 프런트 번들을 함께 반영한다. 기존 `editorial.js` 정적/동적 import 병용 경고는 남아 있다.
- 소스·문서의 staged diff 공백 검사 통과. 새 빌드 번들에는 기존 샘플 데이터 문자열의 줄 끝 공백 경고 1건이 있다. 생성 파일을 손으로 수정하지 않고 빌드 결과를 보존한다. 변경된 소스·문서·빌드 파일에서 주요 토큰 형식과 DB·세션·환경 파일 포함 여부를 검사했다. 사용자 저장 데이터와 로그인 프로필은 업로드 대상에서 제외한다.
- Core/Python 구현과 main 브랜치에는 변경을 만들지 않았다. 공통 저장 연결은 플랫폼 필드 복원 부분만 최소 수정했다.

## 남은 확인

- Threads 실제 AI 새 생성은 승인 검토에서 차단되어 미실행이다. 기존 오류 실행의 정확한 실패 필드는 소급 특정하지 못했다. 자동 테스트 통과를 해당 실제 AI 오류 해결로 단정하지 않는다.
- 실제 Instagram/Threads 사이트에서 전체 카드 첨부·원고 입력을 끝내는 시험과 게시 결과는 이번 최종 검증에 포함하지 않는다.
- 문안이 실제 JPG 영역을 초과하거나 근거가 불일치하면 계속 오류를 표시한다. 생성 완료를 무조건 SNS 준비 완료로 처리하지 않는다.
- 기존 저장 초안은 변경된 생성 규칙으로 자동 갱신되지 않는다. 새 생성 또는 명시적 편집이 필요하다.
