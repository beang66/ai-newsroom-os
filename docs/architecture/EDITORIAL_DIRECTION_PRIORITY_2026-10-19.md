# Instagram·Threads 편집 방향 우선순위

- 추가 입력이 없으면 Instagram 본문·마무리는 습니다체, Threads 본문은 설명형 반말체를 유지한다. 기본 제목은 명사형이다.
- 사실·원문 근거·필수 출력 구조 안에서 사용자가 명시한 문체를 플랫폼 기본 문체보다 우선한다.
- `platform-generator/lib/editorial-direction.js`가 플랫폼 범위와 도입/본문/마무리의 문체를 해석한다. 명사체·명사형, 습니다체·존댓말, 해요체, 한다체·기사체, 반말체·구어체와 대표적인 부정 표현을 처리한다.
- 플랫폼 이름이 없는 지시는 공통으로, 플랫폼을 명시한 지시는 해당 플랫폼과 이어지는 부분 지시에 적용한다. 같은 항목의 여러 문체 지시는 뒤에 나온 것을 적용한다.
- 생성 요청·코드 검사·AI 검수·Threads 화면 경고가 같은 해석을 사용한다. 다른 플랫폼용 요구사항은 현재 플랫폼의 AI 입력에서 제외하며 원래 사용자 입력은 결과 메타데이터에 보존한다.
- 명사체 요청을 기본 습니다체/반말체 위반으로 되돌리지 않는다. 명사체여도 계획·확정, 주체·조건·인용·불확실성 검수는 유지한다.
- 사용자 입력 아래에 다음 생성에 반영할 문체를 표시한다. `편집 방향 반영해 다시 생성`은 선택한 Instagram·Threads 원고만 새로 만들며 기존 편집 결과를 대체한다. 카드뉴스를 함께 재생성하지 않는다.
- 기존 자유 입력·저장 형식과 Core API는 유지한다. 카드뉴스 작성 프롬프트와 생성 파일은 변경하지 않는다. 검수 재사용은 게시글 문체 기준 버전 변경을 반영한다.

## 검증과 한계

외부 AI 대신 대역을 사용해 실제 생성기·검수 경로의 요청과 반환을 검사한다. 입력 없음, 강조점만 입력, 플랫폼별 문체, 부분별 문체, 명사체 마무리, 부정 요청, 사실 검수 유지와 브라우저 말투 경고를 확인한다. 별도 UI 시험은 입력 없이 생성 버튼이 활성화되고, 문체 요약·재생성 시 원문/조건 전달과 카드 재생성 제외를 확인한다.

문체 해석은 공유 코드로 처리하며 추가 AI 호출이나 필수 입력을 만들지 않는다. 임의의 자연어 지시를 모두 정확히 해석하는 것은 보장하지 않는다. 구체적인 미지원 표현은 예시와 함께 회귀 사례에 추가한다. 실제 운영 AI 출력 품질과 실제 SNS 작성창 준비·게시 결과는 이 대역 시험의 검증 범위에 포함하지 않는다.

최종 검증: 기본 테스트 75개, 생성·검수 회귀 31개, 격리 브라우저 테스트 2개 통과. 최초 브라우저 실행은 전체 HTML 의존성 탐색 중 시간 초과가 있어 전용 캐시·명시한 의존성으로 분리한 뒤 동일 동작 검사를 통과했다. 최종 프런트 빌드 exit 0, 정적 검사 오류 없음(기존 경고 유지). 변경 전 저장한 카드뉴스 생성 파일·적용 규칙 해시와 일치하며, 원래 검수기와 현재 검수기에 같은 합성 카드 입력을 넣은 사실·요구사항 AI 요청도 직렬화 결과가 일치한다.
