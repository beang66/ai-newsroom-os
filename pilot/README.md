# Newsroom OS redesign pilot

원본 애플리케이션과 분리된 독립 Vite 앱입니다.

```powershell
npm.cmd run dev
```

기본 개발 서버: `http://localhost:4173`

## 현재 기능 인벤토리

- 기사 작성: AI 초안, 자료 검색·연결, 제목 추천·확정, 본문 서식, 사진 업로드·캡션·삽입, 동아일보/포털 미리보기, CMS 발행
- 검증: 근거 파일 업로드, 주장 추출, 일치율·충돌·미검증 상태, 수정/건너뛰기, 인용 주석 삽입
- 인터뷰·음성: 파일 업로드, 재생·탐색·배속, 화자별/전체 녹취, 검색, 발언 복사, TXT 다운로드, 기사로 발췌
- 변환·배포: 카드뉴스 편집, 텍스트 서식·정렬, AI 문구 다듬기, 자유 배치·잠금, 사진 검색·업로드, 카드 추가·삭제, Instagram/Threads/Blog 배포
- 데이터맵: 주장·출처·인물/기관 관계, 검색·필터, 그래프/목록 보기, 확대·축소·맞춤, 미연결 주장 확인, 노드 상세·집중 보기, 기사 문장 이동
- 보관함: 전체/작성 중/발행본 필터, 기사 검색, 원고·취재자료·인터뷰·미디어·변환 자산, 버전·발행 이력
- 공통: 자동 저장 상태, 알림, 프로필, 설정

## 파일럿 원칙

- 원본 `src/App.jsx`와 기존 컴포넌트는 수정하지 않는다.
- 파일럿은 `pilot/src`의 전용 토큰과 컴포넌트만 사용한다.
- 실제 동작보다 전체 정보 구조와 모든 주요 화면·행동의 가시성을 우선한다.
- Alpy MCP는 현재 세션에서 연결된 도구가 확인되지 않아 외부 컴포넌트 호출 없이 구현했다.
