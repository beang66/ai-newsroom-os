# Instagram 작성창 연결 UI 변경 기록

작업 브랜치: `feature/platform-generator`. 기존 미커밋 변경을 보존했으며 커밋·push·PR·게시를 실행하지 않았다.

## 이번 변경

- `src/components/PlatformDelivery.jsx`: Instagram만 Chrome 고정 안내와 `Instagram 로그인 연결`, `Instagram 작성창 채우기` 버튼을 표시한다. Threads의 브라우저 선택·세 버튼은 유지한다.
- 기존 status 응답으로 로그인 상태를 2초 간격으로 확인한다. 이전 조회 완료 뒤 다음 조회를 예약하며 중복 클릭과 늦은 응답은 참조 잠금·세대 번호로 방지한다. 화면 이탈·생성/작성창 준비 중에는 예약을 정리하고 이전 조회 응답을 무시한다. 진행 중인 status는 기존 API에 취소 계약이 없어 반환을 기다리되 후속 처리는 하지 않는다.
- 이미 연결된 창 또는 pending 작성창이면 connect를 다시 호출하지 않는다. Chrome 이외 세션은 연결 성공으로 표시하지 않는다. 로그인되었지만 계정 이름을 확인하지 못한 상태를 별도 표시한다.
- 로그인 대기는 5분 후 자동 확인을 중지하고 재연결을 안내한다. 연결 성공 뒤에는 창 닫힘을 확인하기 위해 status 조회를 유지한다. Core busy 및 preparing pending은 실패로 처리하지 않는다.
- prepare 성공 응답의 `success`, `status=ready`, `id`, 전체 이미지 장수가 확인되어야 완료 안내를 표시한다. 게시 버튼은 누르지 않는다.
- `platform-generator/instagram-local-service.js`: 입력·환경 변수와 무관하게 전용 창을 Chrome으로만 실행한다. 기존 페이지는 유지하고 새 about:blank 페이지에만 Instagram을 연다. 페이지/창 닫힘 시 pending을 정리하며 준비 도중 닫힘도 안내한다. 프로필 잠금 해제를 기다려 닫은 직후 재연결 경합을 막는다.
- `platform-generator/sns-browser.js`: 설치 누락·프로필 잠금·기타 실행 실패에 내부 오류 코드를 추가해 Instagram에서 구분 안내한다. Threads의 자동 선택 순서와 기존 오류 문구는 유지한다.
- 숨김 JPG 렌더러·원고 규칙·이미지 보관/최신성·전체 카드 첨부 정책·Core API 계약은 이번 작업에서 변경하지 않았다.

## 검증

- Instagram 서비스 합성 DOM 및 Chrome 실패 테스트 2개 통과. Chrome 채널만 한 번 요청하는지, 합성 카드 파일 선택·줄바꿈 캡션 입력, 기존 작성창 재연결 보존, 페이지/창 닫힘, 준비 도중 닫힘, 공유 미실행을 확인했다. 실제 Instagram 사이트 품질 검증은 아니다.
- 기존 SNS 브라우저 및 플랫폼/Threads 테스트 14개 통과.
- 새 Instagram React 화면 테스트 1개 통과: 중복 클릭, 상태 조회 최대 동시 수 1, 자동 로그인 감지, 계정 이름 미확인, 기존 연결에 connect 재호출 없음, 다른 브라우저 거부, Core busy/pending, 생성 중 조회 정리, 불완전 prepare 성공 거부, 닫힘 시 준비 안내 해제, 화면 이탈 후 늦은 응답 무시, Threads 기존 UI 유지.
- 기존 JPG 편집실 화면 테스트 1개 통과. 새 prepare 성공 계약에 맞춰 모의 반환값만 보완했다. 수정 카드만 재렌더하고 준비 때 정상 JPG를 재사용하는 기존 경로를 확인했다.
- 병렬 Vite 테스트의 캐시 공유로 발생한 초기 로딩 실패는 새 Instagram 테스트의 별도 캐시 디렉터리로 분리했다. 최종 테스트 통과를 확인했다.
- API 경계 검사 통과. `npm run build` 통과. 기존 editorial.js 동적/정적 import 중복 경고는 남아 있다.

## 실제 앱 확인과 한계

- 실제 Chrome의 `http://127.0.0.1:5173/#convert`에서 새 버튼·브라우저 고정 안내·자동 로그인 연결 표시를 확인했다. 기사 원문·계정 이름·세션 정보는 기록하지 않았다.
- 현재 실제 카드 결과는 최신 JPG 4/5장이고 5번 카드 상세 설명 높이 초과가 표시되어 있다. 해당 결과를 변경하거나 일부 카드만 첨부하지 않았다. 실제 Instagram 작성창에 전체 카드와 캡션을 넣는 최종 동작은 검증하지 못했다.
- 실행 중인 SNS Node 프로세스는 서비스 코드 수정 전부터 존재한다. 새 서비스 코드까지 실제 앱에 적용하려면 로컬 앱/Core를 재시작해야 한다. 기존 창·작업을 보호하기 위해 강제 종료하지 않았다. 현재 실제 연결 표시는 새 프런트 UI 확인이며 새 서비스 전체 경로 검증으로 해석하지 않는다.
- 실제 게시 및 AI 호출 없음. 테스트는 합성 입력만 사용했다.
