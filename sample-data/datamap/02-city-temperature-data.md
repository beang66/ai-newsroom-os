# 도시 기온 관측 데이터

## 관측 개요

2026년 7월 15일부터 21일까지 도심 8곳과 외곽 3곳의 오후 3시·밤 11시 기온을 같은 규격의 센서로 측정했다. 야간 평균 격차는 2.4℃였다.

## 해석 주의점

- 센서 높이와 복사열 차이를 통제하지 않은 지점은 기사 수치에서 제외한다.
- 전체 취재 방향은 [[01-urban-heat-overview|도심 열섬 취재 개요]]를 따른다.
- 추가 센서 설치 비용은 [센서 확충 예산](04-budget-and-policy.md#센서-확충-예산)을 참고한다.
- 수치 표현의 검증 결과는 [[05-factcheck-notes#기온-수치]]에 기록했다.

코드 블록 안의 [[가짜-링크]]는 인덱싱되면 안 된다.
